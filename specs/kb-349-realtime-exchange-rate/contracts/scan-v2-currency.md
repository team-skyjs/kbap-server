# Contract: 2.0 스캔 응답 `currency` (KB-349 이후)

**와이어 계약 불변.** 바뀌는 것은 값의 출처와 null 이 되는 조건뿐.

```json
"currency": { "code": "JPY", "krwPerUnit": 8.8295 }   // 또는 null
```

| 항목 | 전 (KB-323) | 후 (KB-349) |
|---|---|---|
| `krwPerUnit` 출처 | 코드 상수(은행 고시 스냅샷) | frankfurter(ECB) 최근 고시 — 스캔 요청마다 조회(캐시 없음) |
| 의미·자릿수 | 1단위당 원화, 4자리 | 동일 |
| `currency = null` 조건 | 없음(요청 `currency` 필수라 항상 채워짐) | **제공처 조회 실패**(오류·타임아웃·누락) — 그 요청에 한해 |
| 요청 `currency` 파라미터 | 46종 중 하나, 그 외 400 `INVALID_CURRENCY_CODE` | **30종** 중 하나, 그 외 400 동일 |
| 스캔 본문(`results`·`degraded`) | — | 환율과 무관하게 항상 정상 |

## 클라이언트 공유 요점

1. `currency` 가 `null` 로 올 수 있다 — 이미 nullable 계약이었지만 이제 실제로 발생한다(제공처 장애·지연 시, 요청 단위). 환산 UI 를 숨기고 원화만 보여주면 된다.
2. 통화 선택지가 46 → 30 으로 준다. 폐기된 코드(VND·TWD·SAR·AED 등)를 요청에 보내면 400. 회원 프로필 통화도 같은 목록 — 폐기 통화 회원은 서버가 USD 로 옮겨 뒀다.
3. "실시간"이 아니라 **일 1회 고시값**이다. UI 에 "실시간 환율" 표기는 하지 말 것. 기준 시각은 내려주지 않는다.
