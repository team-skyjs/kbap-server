# Contracts: 아키텍처 단순화 (KB-134)

**이 기능은 외부 계약을 하나도 바꾸지 않는다.** 신규·변경·삭제되는 엔드포인트, 요청/응답 DTO, 오류 코드, DB 스키마가 전부 0건이다(spec FR-014, Out of Scope "API 계약 변경").

## 계약 회귀 고정 방법

- **기존 `app:api` MockMvc 통합 테스트 스위트가 계약의 실행 가능한 명세다.** 컨트롤러·DTO·`BaseResponse` 봉투·오류 응답을 검증하는 기존 테스트를 리팩토링 후에도 전부 green 으로 유지한다 — 이 스위트가 곧 "응답이 바뀌지 않았다"의 증거다(SC-003).
- 컨트롤러·API DTO(`com.meogo.app.api`)는 이번 변경에서 **소스 수정 없음**(유스케이스 시그니처가 유지되는 한 import 도 무변경).
- Swagger(springdoc) 산출물은 리팩토링 전후 동일해야 한다 — 구현 검증 단계(quickstart)에서 로컬 부팅으로 육안 확인.
