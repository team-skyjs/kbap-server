## 제거되는 것 (P2 의 구체 대상)

현행 `SYSTEM_PROMPT` 의 `[진실의 출처]` 절 전체가 대상이다. 이 절은 "OCR 과 사진을 대조해 교정하라"는 **양방향 판정**을 지시하며, 그 결과 OCR 품질이 판독에 직접 개입한다.

특히 다음 두 문장은 **반드시 사라져야 한다** — OCR 을 사진보다 우선시키는 경로다:

- `사진에서 확실히 판독되지 않을 때도 OCR 을 보존한다` — 사진이 불확실하면 OCR 텍스트가 그대로 결과가 된다.
- `사진에 근거가 없는 OCR 항목(환각)은 결과에서 제외한다` — OCR 항목을 "검사할 후보 목록"으로 전제한다.

## 유지되는 것 (건드리지 않는다)

- `[규칙]` 절 전체 — `name`/`koreanName`(순수 한국어, DB 조회 키)/`price`(정수 KRW, 축약 환산)/메뉴 아닌 텍스트 제외/사이즈별 분리.
- `[matchedIdx]` 의 커버리지 규칙 — 조각 병합 시 `idx` 하나만 부여, 중복 금지.
- 응답 형식 문장과 코드펜스 금지.

`koreanName` 규칙은 헌법 원칙 V 의 언어 정책(DB 조회 키가 되는 한국어 원문)과 직결되므로 이번 변경 범위 밖이다.

## 구조 (목표 형태)

```
[역할 + 응답 형식]          ← 유지
[판독 — 사진 단독]          ← [진실의 출처] 를 대체. P1·P2·P4
[규칙]                      ← 유지
[매칭 — OCR 참조표]         ← 기존 [matchedIdx — 커버리지] 를 흡수·재라벨. P3·P6
```

두 절의 순서가 의미를 갖는다: **판독을 먼저 끝내고 나서 매칭한다**는 것을 절 순서로도 드러낸다. OCR 목록은 매칭 절에 도달하기 전까지 등장하지 않는다.
