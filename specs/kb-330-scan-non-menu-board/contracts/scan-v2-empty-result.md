# Contract: 스캔 2.0 메뉴판 아님 에러 (SCAN-003)

```
POST /api/scans  (X-API-Version: 2.0 — 기존 v2 매핑 그대로)
```

**메뉴판으로 추정되지 않는 사진 → 400 Bad Request** (신규 에러 코드)

```json
{
  "success": false,
  "payload": null,
  "message": "메뉴판을 인식하지 못했습니다. 메뉴판이 잘 보이게 다시 찍어주세요",
  "code": "SCAN-003"
}
```

- 클라이언트는 `code == "SCAN-003"` 으로만 분기해 재촬영 안내 UI 를 띄운다 (`message` 매칭 금지 — 문구는 자유 변경).
- **SCAN-002(503) 와의 구분**: SCAN-003 은 사용자 귀책(사진이 메뉴판이 아님 — 재촬영 유도), SCAN-002 는 시스템 장애(모델 호출·형식 실패 — 잠시 후 재시도). 비메뉴판 사진이 5xx 지표를 오염시키지 않는다.
- 성공 응답에 지어낸 메뉴 항목이 포함되어서는 안 된다 — 프롬프트의 환각 제외 규칙이 "메뉴판 아님 = 빈 추출"을 결정적 신호로 만들고, 서버가 v2 경로에서 빈 추출을 SCAN-003 으로 변환한다.
- **1.0 스캔은 무변경** — 빈 추출은 기존대로 200 + 빈 results (구 클라이언트 계약 유지).
- 정상 메뉴판 사진의 응답(items 채워짐)은 변경 전과 동등해야 한다.
