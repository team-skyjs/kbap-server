# Contract: 스캔 2.0 빈 결과 응답 (메뉴판 아닌 사진)

API 계약 변경 없음 — 기존 2.0 스캔 응답의 "빈 결과" 형태를 비메뉴판 사진의 표준 결과로 고정한다.

```
POST /api/scans  (X-API-Version: 2.0 계열 — 기존 v2 매핑 그대로)
```

**메뉴판이 아닌 사진 → 200 OK** (1.0 이 빈 결과를 반환할 때와 동일 형태)

```json
{
  "success": true,
  "payload": {
    "items": [],
    "degraded": false
  },
  "message": null,
  "code": null
}
```

- 지어낸 메뉴 항목이 포함되어서는 안 된다 — `items` 는 빈 배열.
- 빈 결과에 대한 재촬영 안내 UI 는 클라이언트 책임.
- 인식 응답 형식 붕괴 시의 `SCAN-002`(503) 계약은 기존 그대로 유지(이 기능 범위 밖).
- 정상 메뉴판 사진의 응답(items 채워짐)은 변경 전과 동등해야 한다.
