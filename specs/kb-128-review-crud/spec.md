# Feature Specification: 리뷰 CRUD — 별점·본문·사진(≤3) + 전체/같은 국적 평점

**Feature Branch**: `kb-128-review-crud`

**Created**: 2026-07-29

**Status**: Draft

**Input**: User description: "KB-128 [BE] 리뷰 CRUD API — 별점·본문·사진(≤3) + 전체/같은 국적 평점 (워크트리)"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 리뷰 작성·수정·삭제 (Priority: P1)

로그인한 회원은 어떤 음식에든 리뷰를 자유롭게 작성한다. 리뷰 1건은 별점(1~5, 필수)과 본문(선택, 최대 1000자), 사진(선택, 최대 3장 — 미리 업로드한 이미지)으로 구성된다. 같은 회원이 같은 음식에 여러 건 작성할 수 있다. 본인이 쓴 리뷰는 별점·본문·사진을 수정하거나 삭제할 수 있고, 타인의 리뷰는 손댈 수 없다.

**Why this priority**: 리뷰 데이터가 존재해야 평점 노출·목록 조회가 의미를 가진다. 작성이 없으면 나머지 스토리는 빈 화면이다.

**Independent Test**: 회원 계정으로 리뷰를 작성→수정→삭제하는 전 과정을 단독으로 검증할 수 있고, 그 자체로 "음식에 의견을 남긴다"는 핵심 가치를 전달한다.

**Acceptance Scenarios**:

1. **Given** 로그인한 회원, **When** 음식에 별점 4·본문·사진 2장으로 리뷰를 작성하면, **Then** 리뷰가 저장되고 성공 응답을 받는다
2. **Given** 로그인한 회원, **When** 별점 없이 또는 별점 0·6 으로 작성하면, **Then** 검증 실패로 거부된다
3. **Given** 로그인한 회원, **When** 본문 1001자 또는 사진 4장으로 작성하면, **Then** 검증 실패로 거부된다
4. **Given** 본인이 쓴 리뷰, **When** 별점·본문·사진을 수정하면, **Then** 변경 내용이 반영된다
5. **Given** 타인이 쓴 리뷰, **When** 수정 또는 삭제를 시도하면, **Then** 권한 없음(403)으로 거부된다
6. **Given** 본인이 쓴 리뷰, **When** 삭제하면, **Then** 리뷰가 목록·평점 집계에서 즉시 제외된다
7. **Given** 비로그인 사용자, **When** 리뷰 작성을 시도하면, **Then** 인증 필요(401)로 거부된다
8. **Given** 본인이 업로드하지 않은 이미지 경로, **When** 그 경로로 리뷰를 작성·수정하면, **Then** 거부된다

---

### User Story 2 - 음식 상세의 전체/같은 국적 평점 노출 (Priority: P2)

음식 상세 페이지에서 사용자는 그 음식의 전체 리뷰 평균 별점(소수 첫째 자리)과 리뷰 수를 본다. 로그인했고 국적이 있는 회원은 추가로 "나와 같은 국적 사람들"의 평균 별점을 본다. 비회원이거나 국적이 없는 회원에게 같은 국적 평점은 값 없음(null)으로 내려가고, 블러 등 표현은 클라이언트가 결정한다. 같은 국적 판정은 리뷰 작성 시점의 작성자 국적 스냅샷 기준이다 — 회원이 이후 국적을 바꿔도 과거 리뷰의 소속 국적은 변하지 않는다.

**Why this priority**: 평점은 음식 탐색의 핵심 판단 재료이고, 같은 국적 평점은 이 서비스의 차별 가치다. 단 리뷰 작성(P1)이 선행돼야 한다.

**Independent Test**: 리뷰 데이터를 몇 건 만든 뒤 음식 상세를 회원(국적 보유/미보유)·비회원으로 각각 조회해 세 값의 노출 규칙을 단독 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 리뷰가 여러 건인 음식, **When** 누구든 상세를 조회하면, **Then** 전체 평균 별점(소수 첫째 자리)과 리뷰 수를 받는다
2. **Given** 국적이 있는 로그인 회원, **When** 상세를 조회하면, **Then** 본인 국적 작성자들의 평균 별점(소수 첫째 자리)을 추가로 받는다
3. **Given** 비회원 또는 국적 미보유 회원, **When** 상세를 조회하면, **Then** 같은 국적 평점은 값 없음(null)이다
4. **Given** 리뷰가 없는 음식, **When** 상세를 조회하면, **Then** 리뷰 수 0이고 평균 별점은 값 없음이다
5. **Given** 국적을 A→B 로 바꾼 회원의 과거 리뷰, **When** A 국적 회원이 상세를 조회하면, **Then** 그 리뷰는 여전히 A 국적 평점에 포함된다

---

### User Story 3 - 리뷰 목록 조회 (음식별·내 리뷰) (Priority: P3)

사용자는 음식 상세의 평점 영역에서 버튼을 눌러 그 음식의 리뷰 리스트로 진입한다 — 전체 리뷰 또는 같은 국적 리뷰(국적 필터)를 최신순으로 20개씩 이어서 본다. 프로필 탭에서는 내가 쓴 리뷰 목록을 최신순으로 본다.

**Why this priority**: 평점 숫자 뒤의 실제 의견을 읽는 흐름. 작성(P1)·평점(P2)이 있어야 진입점이 생긴다.

**Independent Test**: 리뷰 21건 이상을 만들어 목록 첫 페이지 20건·다음 페이지 이어보기·국적 필터·내 리뷰 목록을 단독 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 리뷰 25건인 음식, **When** 목록을 조회하면, **Then** 최신순 20건과 다음 페이지 커서를 받고, 커서로 이어 조회하면 나머지 5건을 받는다
2. **Given** 여러 국적의 리뷰가 섞인 음식, **When** 특정 국적으로 필터해 조회하면, **Then** 그 국적 작성 시점 스냅샷의 리뷰만 최신순으로 받는다
3. **Given** 여러 음식에 리뷰를 쓴 회원, **When** 내 리뷰 목록을 조회하면, **Then** 본인 리뷰만 최신순으로 받는다
4. **Given** 비로그인 사용자, **When** 음식별 리뷰 목록 또는 내 리뷰 목록을 조회하면, **Then** 인증 필요(401)로 거부된다
5. **Given** 삭제된 리뷰, **When** 어떤 목록을 조회해도, **Then** 그 리뷰는 나타나지 않는다

---

### User Story 4 - 리뷰 활동의 랭킹 카운트 반영 (Priority: P4)

회원의 리뷰 활동은 랭킹 포인트 산정용 카운트 두 가지 — 누적 리뷰 수, 리뷰한 고유 음식 수 — 에 즉시 반영된다. 작성 시 리뷰 수가 1 증가하고 그 음식의 첫 리뷰라면 고유 음식 수도 1 증가한다. 삭제 시 역방향으로 감소하며, 그 음식의 마지막 리뷰를 지운 경우에만 고유 음식 수가 감소한다. 동시에 여러 요청이 겹쳐도 카운트가 어긋나지 않는다.

**Why this priority**: 사용자에게 직접 보이는 화면은 아니지만 랭킹 정합성을 좌우한다. 작성/삭제(P1)에 부수되는 정합 규칙.

**Independent Test**: 한 회원이 같은 음식에 2건 작성→1건 삭제→마지막 1건 삭제하는 시나리오로 두 카운트의 증감을 단독 검증할 수 있다.

**Acceptance Scenarios**:

1. **Given** 리뷰가 없는 회원, **When** 음식 A에 첫 리뷰를 작성하면, **Then** 리뷰 수 1·고유 음식 수 1이 된다
2. **Given** 음식 A에 리뷰 1건인 회원, **When** 음식 A에 두 번째 리뷰를 작성하면, **Then** 리뷰 수 2·고유 음식 수는 1 그대로다
3. **Given** 음식 A에 리뷰 2건인 회원, **When** 1건을 삭제하면, **Then** 리뷰 수 1·고유 음식 수 1이 유지된다
4. **Given** 음식 A에 리뷰 1건 남은 회원, **When** 그 리뷰를 삭제하면, **Then** 리뷰 수 0·고유 음식 수 0이 된다

---

### Edge Cases

- 별점 경계값(1·5)은 허용, 범위 밖(0·6)과 소수 별점은 거부된다
- 본문 정확히 1000자·사진 정확히 3장은 허용 경계다
- 본문·사진 없이 별점만으로 작성할 수 있다
- 수정으로 사진을 전부 제거하거나 본문을 비울 수 있다
- 존재하지 않는 음식·리뷰를 대상으로 한 요청은 대상 없음으로 거부된다
- 이미 삭제된 리뷰를 다시 수정·삭제하려는 요청은 대상 없음으로 처리된다
- 국적이 없는 회원이 리뷰를 작성하면 그 리뷰는 어떤 국적 필터·같은 국적 평점에도 잡히지 않는다(전체 평점에는 포함)
- 국적 필터에 리뷰가 한 건도 없는 국적을 넣으면 빈 목록을 받는다
- 삭제된 리뷰는 평점 평균·리뷰 수·모든 목록에서 제외된다
- 같은 회원의 작성/삭제가 동시에 겹쳐도 랭킹 카운트는 정확히 유지된다

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 로그인 회원은 어떤 음식에든 리뷰를 작성할 수 있어야 한다 — 별점(1~5 정수) 필수, 본문(최대 1000자) 선택, 사진(최대 3장) 선택. 같은 회원·같은 음식 개수 제한 없음
- **FR-002**: 별점 범위 밖, 본문 길이 초과, 사진 수 초과 요청은 검증 실패로 거부해야 한다
- **FR-003**: 리뷰 사진은 사전에 리뷰 용도로 업로드 완료된 이미지 경로만 허용하며, 본인이 업로드한 경로인지 확인해야 한다
- **FR-004**: 리뷰 작성 시점의 작성자 국적을 리뷰에 스냅샷으로 보존해야 한다 — 이후 회원 국적이 바뀌어도 과거 리뷰의 소속 국적은 불변
- **FR-005**: 본인 리뷰만 수정(별점·본문·사진)·삭제할 수 있어야 하며, 타인 리뷰 대상 요청은 권한 없음으로 거부해야 한다
- **FR-006**: 리뷰 삭제는 소프트 삭제로 처리하고, 삭제된 리뷰는 모든 목록·평점 집계에서 제외해야 한다
- **FR-007**: 음식 상세 응답에 전체 평균 별점(소수 첫째 자리)과 리뷰 수를 포함해야 한다 — 로그인 여부와 무관하게 제공
- **FR-008**: 음식 상세 응답의 같은 국적 평균 별점(소수 첫째 자리)은 국적 보유 로그인 회원에게만 값을 주고, 비회원·국적 미보유 회원에게는 값 없음(null)을 내려야 한다 — 블러 등 표현은 클라이언트 소관
- **FR-009**: 같은 국적 평점·국적 필터는 리뷰의 작성 시점 국적 스냅샷 기준으로 계산해야 한다
- **FR-010**: 음식별 리뷰 목록을 최신순 20건 단위 커서 방식으로 제공해야 하며, 국적 필터를 지원해야 한다 — 로그인 필수
- **FR-011**: 내가 쓴 리뷰 목록을 최신순 커서 방식으로 제공해야 한다 — 로그인 필수
- **FR-012**: 리뷰 작성·수정·삭제·목록 조회는 로그인 필수이며, 비로그인 요청은 인증 필요로 거부해야 한다 (음식 상세는 비로그인 접근 허용)
- **FR-013**: 리뷰 작성 시 회원의 누적 리뷰 수를 1 증가시키고, 해당 음식의 첫 리뷰면 고유 음식 수도 1 증가시켜야 한다
- **FR-014**: 리뷰 삭제 시 누적 리뷰 수를 1 감소시키고, 해당 음식의 마지막 리뷰면 고유 음식 수도 1 감소시켜야 한다
- **FR-015**: 랭킹 카운트 증감은 동시 요청이 겹쳐도 어긋나지 않아야 한다 (읽고-더해-쓰기 금지)
- **FR-016**: 평균 별점은 별도 저장값 없이 조회 시점에 실제 리뷰로부터 계산해야 한다

### Key Entities

- **리뷰(Review)**: 회원이 음식에 남긴 평가 1건 — 별점(1~5), 본문(≤1000자, 없을 수 있음), 사진 참조(≤3, 없을 수 있음), 작성자, 대상 음식, 작성 시점 작성자 국적 스냅샷, 소프트 삭제 상태
- **회원 랭킹 카운트**: 기존 회원에 속한 누적 리뷰 수·리뷰한 고유 음식 수 — 리뷰 작성/삭제에 원자적으로 연동
- **음식**: 기존 엔티티 — 상세 조회 응답이 평점 집계(전체/같은 국적/리뷰 수)로 확장된다

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 회원은 별점만으로 10초 이내에 리뷰 작성을 완료할 수 있다
- **SC-002**: 검증 위반(별점 범위·본문 길이·사진 수·타인 리뷰·미인증) 요청은 100% 거부되고 명확한 실패 사유 코드를 받는다
- **SC-003**: 음식 상세의 평점 3종(전체/같은 국적/리뷰 수)은 리뷰 작성·삭제 직후 조회에서 즉시 최신 값으로 반영된다
- **SC-004**: 국적 변경 회원의 과거 리뷰 국적 소속이 100% 불변으로 유지된다
- **SC-005**: 작성→삭제 시나리오 전 조합(첫/추가/마지막 리뷰)에서 랭킹 카운트 2종의 정합이 100% 유지된다
- **SC-006**: 리뷰 목록은 20건 단위로 끊김 없이 이어 볼 수 있고, 누락·중복 없이 전 리뷰를 순회할 수 있다

## Assumptions

- 리뷰 사진의 업로드 절차(리뷰 용도 사전 업로드)는 기 구현돼 있으며 이 기능은 업로드 완료 경로를 받기만 한다
- 기존 로그인/인증 체계를 그대로 사용하며, 보호 경로 기본 정책(deny-by-default)에 따라 신규 리뷰 경로는 자동 보호된다
- 평점 표시는 소수 첫째 자리 반올림으로 통일한다
- 같은 국적 평점의 블러/숨김 등 시각 처리는 클라이언트 책임이고, 서버는 값 유무(null 여부)만 전달한다
- 리뷰 신고·차단·베스트 정렬 등은 이 기능 범위 밖이다
- 랭킹 포인트 산정식 자체는 별도 기능이며, 여기서는 카운트 2종의 정확한 증감만 책임진다
- 사진 원본의 보관·삭제 수명주기는 리뷰와 함께 관리되며 별도 정리 절차는 범위 밖이다
